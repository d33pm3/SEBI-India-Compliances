# Contributing

## Ground rules

1. Keep the repository free of secrets and real-world tenant data.
2. Use fictional names and `example.com` addresses in fixtures.
3. Do not add production configuration, internal URLs, or live filing documents.
4. Prefer small pull requests with a clear purpose.

## Development

```bash
npm install
npm run lint
npm run test
```

Open a pull request against `main`. First-time contributors may see workflow approval on GitHub Actions.
